# Hide Free Sign-In Button

תוסף Chrome (Manifest V3) שמסתיר כפתורי התחברות/הרשמה לחשבון חינמי בדף claude.ai.

## התקנה (לא ארוזה)

1. פתחו `chrome://extensions`
2. הפעילו "מצב מפתח" (Developer mode)
3. לחצו "טעינת תוסף לא ארוז" (Load unpacked)
4. בחרו את התיקייה `chrome-extension`

## איך זה עובד

`content.js` נטען בדפי `claude.ai`, סורק קישורים וכפתורים, ומסתיר כל אלמנט שהטקסט שלו תואם לביטויים כמו "Sign in", "Log in", "Sign up", "Get started", "התחבר", "הרשמה" וכדומה. `MutationObserver` דואג לתפוס גם אלמנטים שנטענים דינמית לאחר טעינת הדף הראשונית.

אם claude.ai משנה את הטקסט של הכפתור, יש לעדכן את הרשימה `TEXT_PATTERNS` בקובץ `content.js`.

## מגבלה ידועה

Chrome אינו מאפשר לתוסף לחסום, ליירט או לדרוש סיסמה לפני הסרתו על ידי המשתמש (דרך `chrome://extensions` או לחיצה ימנית). לכן התוסף הזה עוסק רק בהסתרת הכפתור, ואינו כולל הגנת סיסמה על הסרה — פיצ'ר כזה לא ניתן למימוש אמיתי ב-API של Chrome.
