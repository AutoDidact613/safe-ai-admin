# Forum Version Manager Agent

אייג'נט אוטונומי מבוסס LangGraph לניהול, אימות ושחרור גרסאות עבור רכיב הפורום.

## תכונות עיקריות
- **Guardrail:** סינון וחסימת בקשות שאינן עוסקות בניהול שחרור או מכילות ניסיונות עקיפה.
- **Data Collection & Code Execution:** הרצה אוטומטית של בדיקות תקינות וטייפצ'ק (כולל תמיכה דינמית בטסטים עתידיים) ושליפת לוגי שגיאות מ-MongoDB.
- **Multi-Model Consensus:** ניתוח מקבילי של שני מודלים, חישוב ציון מוכנות וזיהוי סתירות.
- **Human-in-the-Loop (HITL):** עצירת הגרף להכרעה אנושית לפני הפקת השחרור הסופי.
- **HTML Release Report:** הפקת דוח שחרור גרסה מעוצב ועצמאי בתיקיית `reports/`.
- **Tracing & Observability:** תיעוד מלא של שלבי הריצה במסד הנתונים MongoDB בהתאם לסכמת הפרויקט.
